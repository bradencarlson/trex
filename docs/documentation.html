Configuration

All configuration for TreX is done through a simple file located in the root directory of your project. The default config file name is trex.conf. Other config files can be used by specifying the -f option, documented below.

The content of the config file is a sequence of key value pairs of the form key: value. Notice that there is no space before the semicolon, but there is one afterwards.

Key Value Pairs

class

This key is required, and simply specifies the document class of the file. For example, the value could be article, book, etc.

preamble

This key is required, and specifies the filename of the preamble for the document.

section

This key may appear multiple times in the config document, and each specifies a new section in the document. The value should be the intended section name.

file

This key may appear multiple times in the config file, and specifies a file to be included in the document. The value should be the filename of the file to be included.
