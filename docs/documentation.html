Configuration

All configuration for TreX is done through a simple file located in the root directory of your project. The default config file name is trex.conf. Other config files can be used by specifying the -f option, documented below.

The content of the config file is a sequence of key value pairs of the form key: value. Notice that there is no space before the semicolon, but there is one afterwards. This is the only spacing which is important in the config file, any white space at the beginning or end of a line will be ignored.

Since TreX wants to piece your project together piece by piece, it is neccessary to separate your project in a somewhat unusual way. For LaTeX users, the preamble of the document must be in it's own file, and must not contain a \begin{document} command. There also must not be a \end{document} command anywhere in any of the files.

Also, since there is the option to specify sections in the config file, it is recommended to either specify all sections in the config file, or none of them. In the latter case, simply specify each section in the project files like normal. See the example for a demonstration of the first method.

Key Value Pairs

class

This key is required, and simply specifies the document class of the file. For example, the value could be article, book, etc.

preamble

This key is required, and specifies the filename of the preamble for the document.

section

This key may appear multiple times in the config document, and each specifies a new section in the document. The value should be the intended section name.

file

This key may appear multiple times in the config file, and specifies a file to be included in the document. The value should be the filename of the file to be included.

Example Config

Below is an example config file from a series of lecture notes.

class: article
preamble: preamble.tex
section: Linear Equations and Row Reduction
 file: lecture-1.tex
 file: lecture-2.tex
 file: lecture-3.tex
 file: lecture-4.tex
section: Matrices and Matrix Algebra
 file: lecture-5.tex
 file: lecture-6.tex
 file: lecture-7.tex
section: Determinants
 file: lecture-8.tex
 file: lecture-9.tex
 file: lecture-10.tex

With the configuration setup in this way, running the command

trex -r 2 -j filename

will create the file filename.pdf with the contents of lecture 2. The way this is done is by calling pdflatex with the following content:

\documentclass{article}
\input{preamble.tex}
\begin{document}
\setcounter{section}{0}
\section{Linear Equations and Row Reduction}
\input{lecture-2.tex}
\end{document}

Command Line Options

-r

The range to compile. The total number, N, of times the file key appears in the config file defines the maximum number for the range. Otherwise this can be any subset of {1,2,...,N}. For example, to compile only the first file, use -r 1. To compile files 1-3 and file 5, use -r 1-3,5. The default is 1.

-e

The engine to use when compiling. Currently the only engine available is pdflatex. This option should not currently be used.

-j

The jobname. This specifies the filename of the compiled document. For example, to specify that the output file should be named exam-1.pdf, use -j exam-1. The default is "out".

-f

The config file to use. If you do not wish to use the default config file, specify the location of the config file with this option.

-o

Pass options to the compiler. For example, to pass the 12pt option to the article class, use -o 12pt and use class: article in the config file.

-d

Dry run option. Instead of compiling the document, print out the command that would be run.

-v

Verbose output. This will force TreX to print out what it finds in the config file, as well as the command that it will run.
