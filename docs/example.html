Example

Let's see a minimal example. We will create a lecture for a linear algebra class about row reduction. As mentioned in the documentation page, TreX requires that the preamble of the document is located in a separate file, and that the config file is located at the root of the project directory. Suppose our directory structure looks like the following:

project
preamble.tex
sources.bib
chapter-1.tex
chapter-2.tex
chapter-3
subsection-1.tex
subsection-2.tex

We can then create our config file as follows.

class: article
preamble: preamble.tex
section: Chapter 1
 file: chapter-1.tex
section: Chapter 2
 file: chapter-2.tex
section: Chapter 3
 file: chapter-3/subsection-1.tex
 file: chapter-3/subsection-2.tex

Now, suppose that we are satisfied with chapters 1 and 2, and are currently rewriting chapter 3. We can compile just chapter 3 with the command trex -j chapter-3 -r 3-4, since chapter 3 is composed of the third and fourth files in our config file (eventually, I hope to include a more intuitive way to do this, like maybe being able to specify which section to build).
