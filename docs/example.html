Examples

Book Chapters

Suppose you are writing a book, and the project directory looks as follows:

project/
preamble.tex
chapter-1.tex
chapter-2.tex
chapter-3/
subsection-1.tex
subsection-2.tex

As mentioned in the documentation page, TreX requires that the preamble of the document is located in a separate file, and that the config file is located at the root of the project directory. We can then create our config file as follows.

class: article
preamble: preamble.tex
chapter: Awesome Title
 file: chapter-1.tex
chapter: Awesome Title 2
 file: chapter-2.tex
chapter: Awesome Title 3
 file: chapter-3/subsection-1.tex
 file: chapter-3/subsection-2.tex

Now, suppose that we are satisfied with chapters 1 and 2, and are currently rewriting chapter 3. We can compile just chapter 3 with the command trex -j chapter-3 -r 3-4, since chapter 3 is composed of the third and fourth files in our config file. The resulting pdf will be called chapter-3.pdf.

Lecture Notes

When compiling lecture notes, one may have a directory structure as follows:

lectures/
preamble.tex
lecture-1.tex
lecture-2.tex
lecture-3.tex
lecture-4.tex

With this setup, we create the following configuration file:

class: article
preamble: preamble.tex
handle_subsections: true
section: Row Reduction
 file: lecture-1.tex
 file: lecture-2.tex
section: Matrix Algebra
 file: lecture-3.tex
 file: lecture-4.tex

Now we can compile the 3rd lecture with the following command: trex -j lecture-3 -r 3. The resulting pdf file will be called lecture-3.pdf.

Most notably, lecture-3.pdf will start with a section header, with section name "Matrix Algebra". This section will be labeled as section 2, even though it is the only section to appear in the file, since TreX takes into account the rest of the configuration file when compiling. Since the handle_subsections option is declared as true in the config file, TreX will also assume that each file is it's own subsection (probably true if these are sequential lecture notes), and will also keep track of the proper subsection number. For lecture 3, this is simply the first subsection.
